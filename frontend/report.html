BlogSpace Project Report

A Social Blogging & Direct Messaging Platform

CHAPTER 1: INTRODUCTION

1.1 Project Overview

BlogSpace is a full-stack web application that allows people to publish, discover, and discuss written content in a modern social environment. A blog is one of the oldest and most effective forms of online publishing: an individual or an organization writes articles, arranges them by topic, and shares them with a community of readers who can respond through comments, likes, and direct communication. This project builds a complete, high-performance platform for that purpose, where any registered user can become an author, and every visitor can read, search, and interact with published content.

The system is designed around three types of users: Reader, Author, and Administrator. The application follows a decoupled client–server architecture built with standard HTML5, modern CSS3, and Vanilla JavaScript (ES6+), ensuring fast page loads (<200ms) without heavy framework bundle overhead.

1.2 Problem Statement

Although many blogging platforms exist, independent writers face restrictions on hosted platforms unless a paid plan is purchased. Self-hosted content management systems (CMS) are heavy, require complex plugin management, and are difficult for beginners to customize. BlogSpace addresses this need by delivering a lightweight, secure, and fully customizable platform with built-in moderation and direct messaging.

1.3 Objectives

  • Provide secure user registration and login using Bcrypt password hashing (10 salt rounds) and stateless JSON Web Token (JWT) session authorization.
  • Support three distinct user roles—Reader, Author, and Administrator—with Role-Based Access Control (RBAC).
  • Enable authors to create, edit, save as draft, publish, and delete blog posts with cover images and category tags.
  • Allow readers to comment, like, and follow authors with background auto-polling for live notifications.
  • Integrate a direct messaging engine enabling private chats with photo, video, and document file attachments.
  • Enable dual cloud deployment capability across Vercel and Render.

CHAPTER 5: IMPLEMENTATION & TECHNOLOGY STACK

BlogSpace is developed using Node.js and Express.js on the backend, communicating with an embedded SQLite database. The frontend is built using zero-dependency native JavaScript and modern CSS custom properties.

npm start -> node backend/server.js -> http://localhost:3000
